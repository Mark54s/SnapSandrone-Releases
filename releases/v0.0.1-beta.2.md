# VibrationSnap v0.0.1-beta.2

Windows x64 便携测试版，无需安装 Python。

## 下载

下载附件 **VibrationSnap-v0.0.1-beta.2-windows-x64.zip**，完整解压，
进入 `VibrationSnap` 文件夹运行 `VibrationSnap.exe`。必须保留 `_internal`。
**Source code (zip / tar.gz) 只是本下载仓库的说明文件，不是软件。**

## 本次新增

- **Word 图片报告**（导出 → Word 图片报告…）：把选中的已有图卡编成一份新的 `.docx` 图册。
  一个条件一个 Word 标题 3，每张图一段，图题在图下方是可编辑文字，图号是真正的 Word 域，
  全文连续、不按章重排；条件标题的多级编号由 Word 列表给出（`1.1.1`、`1.1.2`）。
- **通道 → 测点/方向映射**：按实际接线指定每个通道的测点号与 X/Y/Z，映射行可拖动排序；
  同一通道多张图卡时保留全部并单独排序。
- **报告配置**：条件文字、映射与图题模板可存成本地 JSON，换工况时按**通道名**自动沿用
  （只补空字段、不覆盖手填值、不复制条件标题/工况描述）；只列出本次选中图卡所属的条件。
- 图片沿用论文样式与既有 8 cm 宽度：段落样式「图片样式」「图题样式」可直接在 Word 里改，
  改动对所有图生效；图片仍是与「报告图片（PNG）」完全相同的全分辨率渲染。

## 沿用功能

- TDMS / CSV / TXT 导入、暂存分组与通道浏览；原始文件只读，默认离线。
- 统一图卡工作区：时域、幅值谱、PSD、STFT、包络谱、倒谱、倍频程及互谱/相干。
- 一卡一图、专注查看、拖动排序，多卡批量参数与自动/手动坐标范围。
- 工作区保存与重开，图片、处理后波形与分析结果导出，自定义图片标题。
- 可选 MATLAB 时域 PNG 原生绘图；普通分析及 Python 导出不需要 MATLAB。

## 注意

- 早期测试版，尚未全面验证所有电脑、DPI 与数据组合；重要结论请独立核对。
- 未代码签名；请核对下载来源与附件 `SHA256SUMS.txt`，不要盲目关闭安全防护。
- 升级前备份程序旁的 `artifacts`、工程文件与导出结果。
- 重新打开工作区后需点击“应用并更新”生成图表。
- 本仓库只提供下载，不包含应用源码或开发历史。
- **Word 报告生成不需要安装 Microsoft Office**（包内已带 python-docx）；查看或编辑生成
  `.docx` 需要 Word 或兼容软件。
- 换工况时先在工作区只选中新工况的图卡，再打开导出对话框；每次导出都会新建
  `VibrationSnap_Word_<时间>` 目录，不覆盖已有报告。
