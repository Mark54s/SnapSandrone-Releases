# VibrationSnap v0.0.1-beta.4 · Windows 便携测试版

默认使用 **大肥鱼（DeepSeek）** 主题，可在「视图 → 外观主题」切换素纸。无需安装 Python，解压后运行 VibrationSnap/VibrationSnap.exe。

本版主要更新：

- 实验接线模板：按板卡通道映射测点/XYZ，一次载入供多个工况沿用；支持工况单独设置、停用映射、批量恢复继承和工程保存。兼容从旧报告配置提取接线。
- Word 载入入口同时识别报告配置和接线模板；保留工况文字、题注和工况例外，应用/导出时才提交。按板卡通道、测点号、XYZ 正倒序排列实际报告图序。
- 测点映射窗口统一主题、表头和按钮样式，加宽生效方式列。默认开启新工作区拖动统一图卡尺寸；已有工程保留原设置。
- 支持自动/固定多列布局、批量图卡尺寸；修复统一尺寸后自动列数不更新。
- 时域单击按预设附近秒窗找峰，并估计峰附近若干周期的平均频率；跨图卡连续标注，全部/选中标记 CSV 汇总。
- 导出窗口与耗时显示、工具卡折叠排序、图形网格/边框/坐标/标题设置、程序资源状态和滤波调试导航改进。

使用已有独立映射的工程时，新模板不会覆盖这些工况例外；需要跟随模板可在测点映射中多选「恢复继承」。停用映射不删除原始信号。工程仍保留原始来源身份，原文件只读，默认离线。

请完整解压 ZIP，保留 _internal。升级时仅替换程序和 _internal，保留自己的工程、模板及 artifacts 暂存数据。新版工程含新功能时旧程序可能无法读取，建议先保留工程副本。

SHA256 见附件 SHA256SUMS.txt。普通图片/Word 生成无需 MATLAB 或 Office；可选 MATLAB 后端需另装授权 MATLAB。原生多电脑/DPI/真实试验数据对照仍需试用，不将自动验证当作全部工程场景验收。
