# VibrationSnap v0.0.1-beta.3

Windows x64 便携测试版，无需安装 Python。完整解压附件
**VibrationSnap-v0.0.1-beta.3-windows-x64.zip**，运行其中
`VibrationSnap/VibrationSnap.exe`，保留 `_internal` 文件夹。
自动生成的 Source code 附件只有下载仓库说明，不是程序。

## 本次更新

- 外观提供 **大肥鱼（DeepSeek）** 和 **素纸** 两种内置主题。在“视图 → 外观主题…”
  选择后点“应用并保存”立即生效，保留当前工作区；无需重启。
- 便携版不加载或导入其他自定义皮肤。若本机此前保存过自定义主题，启动时使用大肥鱼，
  原主题文件和偏好不会被自动删除或覆盖；主动保存内置主题才会更新选择。
- 分析工作区与滤波调试以页签切换；空闲时暂离滤波页可保留输入及候选，
  应用前查看工作区时受只读门禁保护。
- 滤波诊断图的中文与子页签显示改进；保留预览、取消、应用及原卡更新流程。
- 继续提供 Word 图片报告、测点/方向映射、图卡坐标范围及既有图片/数据导出功能。

## 使用与升级

- 默认离线，原始文件只读；无需账号，不上传测试数据。
- 升级请先备份旧程序旁的 `artifacts`、工程文件和导出结果，再解压到新目录。
  新包不含旧版用户暂存数据，勿直接覆盖或删除自己的数据文件。
- Word 报告生成不需要安装 Office；阅读编辑 `.docx` 需要 Word 或兼容软件。
- 普通分析及 Python 图片导出不需要 MATLAB。可选 MATLAB 时域 PNG 后端需要自行安装并授权 MATLAB；
  包内带所需 `.m` 入口，但本次没有执行真实 MATLAB 渲染。
- 仍为早期测试版、未代码签名；不同电脑和 DPI 组合尚未全面验收。下载后可用同页
  `SHA256SUMS.txt` 校验 ZIP。
